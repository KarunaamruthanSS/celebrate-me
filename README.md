# CelebrateMe - Personalized Celebration Page Generator

A modern web application that creates beautiful, animated celebration pages for special occasions.

## Features

- **5 Celebration Types:**
  - Valentine's Day - Floating hearts, love letter animation, romantic gradients
  - Birthday - Balloons, fireworks, confetti, cake animation
  - Anniversary - Elegant gold theme, glowing particles, animated wedding rings
  - Christmas - Falling snow, twinkling lights, gift box animation
  - New Year - Fireworks, countdown, gold particle explosions

- **Fully Standalone Pages:**
  - All CSS and JavaScript embedded
  - No external dependencies
  - Works completely offline
  - Downloadable HTML files

- **Premium Animations:**
  - Smooth CSS keyframe animations
  - Canvas-based particle effects
  - Gradient backgrounds
  - Glowing typography
  - Responsive design

## How to Use

1. Open `celebrate.html` in your web browser
2. Select a celebration type from the left sidebar
3. Fill in the personalized information in the form
4. Click the "Generate" button
5. The celebration page will automatically download as an HTML file
6. Open the downloaded file to view your personalized celebration page

## Technical Details

- Pure HTML, CSS, and JavaScript
- No frameworks or libraries required
- Uses Blob API for file generation
- Canvas API for advanced animations
- CSS animations for smooth effects
- Fully responsive design

## Browser Compatibility

Works in all modern browsers that support:
- ES6 JavaScript
- CSS3 animations
- Canvas API
- Blob API
